# Mis remitos · MiDistri v51

## Guía de uso

### Un filtro para devoluciones
Entrá a MiDistri con tu perfil y elegí Mis remitos. Seleccioná Devolución para ver las guías de preparación y los comprobantes de devolución. Podés acotar los resultados por fecha.

### Abrir una carga anterior
Elegí Carga de consignaciones. Usá Ver / imprimir PDF para consultar o Descargar PDF para guardar. Si el PDF histórico con fotos no está guardado, verás una copia del detalle emitido con un aviso de que faltan las imágenes. Si administrás varios kioscos, elegí primero el perfil correcto.

## Detalle técnico

Instalar Urban Soft v679 primero y MiDistri v51 después. Este paquete parte de v50 y no requiere migraciones. El portal usa el tipo devolucion al listar y acepta enlaces anteriores con preparar_devolucion. Si una respuesta intermedia todavía trae el tipo anterior, la lista lo muestra como Devolución. La API comprueba el kiosco activo en la lista y al abrir cada PDF. Los documentos y sus importes se conservan.

Para revertir, restaurar el código de MiDistri desde el respaldo del instalador. Si se restaura Urban Soft v678, volver a MiDistri v50 para recuperar las opciones de filtro anteriores. Verificar la pantalla de Cerrutti, el único filtro Devolución y las acciones de ver y descargar una carga.
