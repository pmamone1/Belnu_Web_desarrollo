# MiDistri v57 · Saludo y vendedor activo

## Guía de uso

### Identificar la persona y el kiosco
El encabezado saluda con el nombre de la persona identificada y muestra debajo el nombre del vendedor activo. Si usás más de un kiosco, Cambiar perfil identifica el vendedor con el que vas a consultar los remitos o el estado de cuenta.

## Detalle técnico

El nombre del vendedor hereda el color del encabezado para conservar el contraste de cada tema. Requiere MiDistri v56. Sin migraciones. Para revertir la versión, usar --restore sobre el respaldo de código creado por el instalador v57. Revisar la lectura del vendedor en los cuatro temas disponibles.
