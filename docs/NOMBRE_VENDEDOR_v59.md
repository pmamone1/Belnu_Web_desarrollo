# MiDistri v59 · Nombre del vendedor

## Guía de uso

### Identificar el vendedor activo
Debajo del saludo, el nombre del vendedor se destaca en negrita y con mayor tamaño. Revisalo cuando cambies de perfil para saber qué remitos y qué estado de cuenta estás consultando.

## Detalle técnico

La plantilla base destaca sólo el nombre del vendedor y conserva los colores del tema. La actualización requiere v58 y es sólo de código. Para revertirla, se puede usar --restore sobre el respaldo que genera el instalador. Verificar la lectura con dos tamaños de pantalla y después de cambiar de perfil.
